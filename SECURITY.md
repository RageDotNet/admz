# Security policy

If you believe you have found a security issue in Agent DMZ, **open a GitHub issue** on this repository. Describe the problem and impact; do not include exploit code or a full attack walkthrough.

This project is a broker for untrusted agent traffic. Issues that affect isolation, authentication, or secret handling are especially useful to report.

There is no separate private disclosure channel. Use the public issue tracker.

Supported versions: the latest code on the default branch.
